# Node view function + review step enrichment

Date: 2026-05-10

## What changed

### steps/view.py (new)

`node_view(vault, summary_uri, siren_uri=None, eval_uri=None)` compiles a
markdown snapshot of a node from vault artifacts.

- `summary_uri` is mandatory (the DDG summary text).
- `siren_uri` and `eval_uri` are optional — sections are omitted when absent.
- Renders three sections separated by `---`:
  - **Company header** — name, SIREN, NAF, category, headcount band, city
    (parsed from the raw Recherche Entreprises JSON, same logic as the old
    `NodeDir.get_siren_meta()`).
  - **Summary** — the DDG summary text verbatim.
  - **Eval** — score label, fit sentence, dealbreakers, uncertainty.

The function is pure (no queue access) — callers pass URIs directly.

### steps/review_step.py

`scan()` now resolves all three URIs eagerly for each candidate:
- `summary_uri` from the `summarize_ddg` done event (was already there).
- `siren_uri` from the latest `fetch_siren` done event for the node.
- `eval_uri` from the latest `eval` done event for the node.

All three are stored in `args`, so `work()` receives them without re-querying
the queue. `work()` calls `node_view()` and displays the result via
`rich.Markdown` instead of the previous ad-hoc summary-only print.

The `siren_uri` and `eval_uri` fields are also saved into the review vault
payload for traceability.
