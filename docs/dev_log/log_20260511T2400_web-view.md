# Web view (Flask)

Date: 2026-05-11

## What was done

Added a minimal Flask web UI: `anpe/web.py` + `anpe web` CLI command.

### Layout

Single-page split view: left panel = node table, right panel = iframe showing the
selected node detail. Clicking a row loads the detail without a full page reload.

### Routes

- `GET /` — table of all `status=ok` nodes, sorted by score then node_id.
  Columns: company name + headcount, score (color-coded), reaction.
- `GET /node/<node_id>` — detail page: SIREN metadata, eval (score/fit/dealbreakers/
  uncertainty), next targets (if any), summary text.

### Next targets

`new_targets` from `summarize_ddg_*.json` rendered as a "Next targets" section with
clickable links (opens in new tab). Currently no nodes have this populated — the
extract from the LLM output may be broken and needs investigation.

### Dependency

`flask>=3.1.3` added to `pyproject.toml`.

## Current state

70 tests pass. Web UI works.
